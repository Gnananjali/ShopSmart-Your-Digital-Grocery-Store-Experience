🛒 ShopSmart - Digital Grocery Store App

A modern React-based grocery eCommerce application that allows users to browse products, filter items, and manage a dynamic shopping cart using Context API.

🚀 Features

Browse grocery products

Category filtering

Real-time search

Price sorting (Low → High, High → Low)

Add to cart with quantity tracking

Slide-in cart drawer

Dynamic cart badge count

Live total price calculation

Responsive layout

Modern dark theme UI

Deployed on Vercel

🛠 Tech Stack

React.js

JavaScript (ES6+)

React Context API

CSS3 (Dark UI & Animations)

Vercel (Deployment)
